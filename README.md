# Basic HTML Website

This project is based on the [Basic HTML Website project from roadmap.sh](https://roadmap.sh/projects/basic-html-website).  
The goal of this project is to learn how to structure a website using only **HTML**, focusing on layout and semantics without any styling.

---

## 📘 Project Overview

The purpose of this project is to understand how different sections of a website (like the header, footer, navigation, main content, and sidebar) are structured in HTML.  
This project **does not include CSS or styling** — the focus is on the HTML structure and semantics.

---

## 🧩 Features

- Multiple pages:
  - **Home**
  - **Projects**
  - **Articles**
  - **Contact**
- A navigation bar that is present on all pages.
- Semantic HTML structure for better readability and SEO.
- SEO meta tags on all pages.
- A contact form with fields for:
  - Name  
  - Email  
  - Message

## 🚀 Learning Goals

- Learn to create **multiple HTML pages** in a website.
- Understand **semantic HTML**.
- Learn to add **basic SEO meta tags**.
- Build a structure that can be easily styled later using CSS.

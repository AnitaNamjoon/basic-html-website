# Basic HTML Website

## 📖 Project Overview
This is a **simple multi-page HTML-only website** created to practice structuring web pages using semantic HTML.  
The site demonstrates how to organize content into logical sections that can easily be styled later using CSS.

---

## 🌐 Pages
- **Home** (`index.html`)
- **Projects** (`projects.html`)
- **Articles** (`articles.html`)
- **Contact** (`contact.html`)

Each page includes:
- A **navigation bar** linking to all pages  
- A **semantic layout** with header, main, and footer  
- **SEO meta tags** in the head section  
- The **Contact** page includes a form (Name, Email, Message)

---

## 🎯 Project Goals
- Learn to create **multiple linked HTML pages**
- Practice **semantic HTML** structure
- Organize a project for **easy future styling**
- Add **basic SEO** meta tags
- Create a **contact form**
